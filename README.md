# Scrollyform — Scrollytelling Event RSVP

An interactive scrollytelling RSVP form with ASCII/generative art visualization and smooth step-by-step progress tracking.

## Features

- **Interactive Scrollytelling Experience**: Scroll-driven sections that transition dynamically.
- **Dynamic Side Canvas/Art**: Left-hand reactive generative art responsive to user interaction and scroll steps.
- **Responsive Form Fields**: Full questionnaire covering attendee details, roles, topics, and dietary preferences.
- **Keyboard & Navigation Controls**: Next step triggers and summary review.
- **Dark/Light Mode Ready**: Automatic system theme detection with support for manual overrides.

## Getting Started

Open `index.html` or `Scrollytelling Event RSVP.html` in any modern web browser.
